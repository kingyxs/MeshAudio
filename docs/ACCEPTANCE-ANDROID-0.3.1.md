# Android 0.3.1 内部测试版验收

日期：2026-11-14（Asia/Shanghai）。本轮补齐此前被清理的 Android 原生节点，未改变桌面混音算法。测试 APK 是 debug 签名；不是商店发行包。

## 构建结果

- JDK 17、Gradle 8.10.2、AGP 8.7.3、compile/target SDK 35、min SDK 29。
- 5 项 MSA1 单元测试通过：头部、序号、PCM 数值/声道、980 字节包长与非法输入。
- Android Lint 无错误；剩余警告为文本国际化、同步偏好写入和备份配置建议，不隐藏权限/API 错误。
- APK 与已安装旧版签名一致，覆盖升级保留原设备身份与数据。
- 最终交付文件：`release/android/MeshAudio-Android-0.3.1-debug.apk`（3,599,101 字节）。两组真机报告均绑定同一个 SHA-256：`c41aa56072714bcea7378e06b0cdf3fe2011bac6f5cb58dd590ff014277703ff`。

## 真实手机结果

已授权 Android 14 / API 34 手机分别完成两组 15 项检查：

1. USB reverse + WebSocket 兼容传输。
2. 真实 Wi-Fi 局域网 UDP，包含测试代理定向丢包。

覆盖：升级、连接探测、真实麦克风采集、取消媒体授权不影响麦克风、新授权下双流、两个稳定来源、真实前台服务与通知、单路暂停/恢复、控制断开而音频继续、控制重连、30 秒息屏双流、单路停止不影响另一路、停止后新授权重启、音频连接恢复/四秒定向丢包恢复、全部停止及包数据合法性。未出现 MeshAudio 致命崩溃。

媒体测试由单独、明确允许捕获的 Android 应用播放低幅度 440 Hz 测试音。音频经手机原生 AudioPlaybackCapture、局域网/USB、桌面原生混音与 VB-CABLE，最后从真实 CABLE Output 录得非静音音频。两次约 9.5 秒有效记录均存在测试音频谱；该结果只证明链路和路由，不证明完整音质连续性。

手机 UDP 包为 980 字节，未发现 NaN 或越界幅度。WebSocket 音频使用有界队列；针对旧版二进制入口不响应 ping 的情况关闭音频连接心跳，独立控制心跳保留，避免无故周期重连。

本机机器可读报告：docs/testing/android/device-report.json、wireless-device-report.json；构建和真机日志在 .build-tools/。这些带本机信息的原始记录不进入公开源码。

测试结束后已移除辅助测试应用、USB 端口转发，恢复手机 USB 常亮原值（关闭），停止两路采集并打开主应用待用。既有设备身份保留；桌面用户画布的来源、通道和连线另行深比较确认未被测试改写。

## 公开签名包与验收范围

公开 Release 另附 `MeshAudio-Android-0.3.1-release.apk`：同一源码的 `assembleRelease` 产物，经 `zipalign` + `apksigner` v3 用独立发布密钥签名，`apksigner verify` 与 zipalign 校验通过，摘要见 `SHA256SUMS.txt`。它**不是**上述两组真机报告绑定的 debug 包，签名与体积均不同；真机 15 项检查、覆盖升级与听感链路证据只适用于 debug 包，签名版未在真机重跑，两种签名不能直接覆盖安装。发布密钥保存在源码树之外的私有目录，不进入仓库、CI 或 Release 附件。

## 边界与待验收

- 两组均使用真实手机采集和真实桌面虚拟输入；不是浏览器模拟麦克风。测试独立桌面数据目录与端口，不用用户画布作为测试配置。
- 签名 release 包需在目标手机重新安装并重新授权后，才能按上述项目复验；未复验前不得把 debug 包结果直接写成 release 包已通过。
- 息屏 30 秒仅代表本台 Android 14 的观察结果；Android 10/11、Android 15+ 与不同厂商需分别实测。
- 尚未完成 30 分钟连续性、主观听感、完整端到端延迟与其他厂商/受保护应用兼容性验收。历史桌面音频跳变失败记录仍保留，不能因本轮通过而改标通过。
- 固定 48 kHz PCM，尚无 Opus/省带宽编码；WebSocket 只是兼容传输。
- 已具备独立发布签名，但仍需其他设备与厂商测试；内部测试 APK 与签名预发布包都不应宣传为生产稳定版。
