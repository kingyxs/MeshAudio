# ADR-010：拖动连线、按需安装和公开源码许可

日期：2026-11-14；状态：采纳。

## 连线

沿用三列来源 → 混音通道 → 输出。端口使用 Pointer Events，按住时捕获指针，拖动时预览曲线并验证目标，松开才提交。输入端也可以反向拖动。已有线路不因取消、失焦或非法操作而断开。扩大端口点击区域，保留 Tab/Enter 键盘替代操作。

参考 ComfyUI 的端口拖动和类型约束，未复制其代码、图片或文档。没有引入重路由节点、任意跨列连接或新的图编辑依赖。现有三列布局与音频图约束更适合本项目。

## 安装

NSIS 安装包提供桌面应用、Node、原生音频引擎与独立 AirPlay 插件。首次启动按需选择 Bonjour 和 VB-CABLE，从发布者 HTTPS 地址获取固定版本，校验 SHA-256 与安装器签名，等待安装器结束并重新检测。已存在的组件跳过；失败、取消和需要重启分别显示。驱动与 Apple 运行库不随本项目重新分发。

不静默绕过 Windows 管理员授权或第三方安装器的协议/确认。系统播放不依赖可选虚拟声卡；AirPlay 仍依赖 Bonjour 和可信局域网访问。网络、签名验证服务、UAC 和可能的重启是首次设置的现实边界。

替代方案是下载后让用户自行寻找安装包，或把所有驱动嵌入安装器。前者不够易用；后者增加专有组件分发与权限风险。

## 许可

MeshAudio 自有代码从此版本采用 GPL-3.0-or-later。这样可统一公开维护和随包修改版 UxPlay 的源码交付策略，并允许在遵守 GPL 的条件下商用。第三方组件保持自己的许可；既有 MIT 授权文本保存在 LICENSES/MeshAudio-original-MIT.txt，不撤销历史授权。

改根 LICENSE 不能替代第三方合规。发布必须携带许可证、精确依赖版本、构建脚本、UxPlay 修改源码，以及 GPL/LGPL 等依赖的对应源码。源代码包和二进制包分开交付。不能把 VB-CABLE、Bonjour 称为开源软件，也不能把旧开发目录整体上传。

## 风险

安装器退出码不能单独证明设备可用；必须检测，不可检测且需重启时保留明确待重启状态。无网络和 UAC 取消需可重试。源码导出采用允许清单，排除配置、证书、日志、个人交接记录、SDK、缓存和编译产物。正式公开前仍需干净 Windows 与真实设备验收。
