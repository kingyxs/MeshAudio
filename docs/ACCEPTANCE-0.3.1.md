# 0.3.1 验收记录

日期：2026-11-14（UTC+8）。本次范围为 AirPlay 自动配置、画布滚轮焦点、连线选择及删除控件。

## 行为与验收

- UxPlay 随主安装包自动部署；设置页可一键检查并自动下载安装缺少的 Bonjour，复用摘要和发布者签名验证、安装结果检测与取消/重试逻辑。已安装的 Bonjour 不重装，不下载外部托盘包装器，不在用户电脑编译插件，不自动启动接收线路。文件缺失时明确引导修复主程序。
- 未点击画布时，滚轮在外部页面滚动；点击画布后蓝色边框高亮并允许内部滚动；Esc、点击外部或窗口失焦释放。键盘进入画布同样可激活。滚动/聚焦不写音频配置。
- 移除透明列容器对连线的遮挡。点击曲线可选中线路，在贝塞尔曲线 t=0.5 处显示独立 HTML 删除按钮；控件位于卡片上层，可用键盘访问，删除仅影响所选线路。

## 自动检查

- Vue/TypeScript 检查、19 项前端单元测试及生产构建。
- 18 项页面回归，包含真实鼠标滚轮事件、画布/页面滚动位置、焦点边框、取消、触控连线、居中删除及 AirPlay 配置入口。页面配置入口测试使用隔离响应，不启动系统安装器。
- 6 项新增自动配置隔离测试：依赖安装等待与去重、已有依赖跳过、缺包修复、取消后重试、重启状态、依赖循环拒绝；原 7 项组件生命周期测试继续保留。
- 服务/传输/双线路回归、原页面回归及实际打包应用检查，详见本机机器可读报告。
- 最终 NSIS 安装包解包核验通过：插件 42 个运行文件与构建摘要匹配，Node、原生引擎、许可与手机页面完整。实际 0.3.1 WebView2 应用启动、随包 UxPlay 无视频模式启动、连接详情二维码及测试线路清理通过；测试前后的已有来源、通道和连线逐项保持一致。

本机证据位于 docs/testing/routing/、docs/testing/bundled-airplay-setup-report.json 与 .build-tools/，不带本机 IP/路径上传公开源码。发布附件应由最终构建生成并验证摘要；源码导出仍使用允许清单。

## 验收边界

没有在开发机重复安装驱动或 Bonjour。隔离安装流程、页面交互和打包启动验证不等于干净 Windows 安装通过。真实 iPhone 的长时间音频连续性、历史波形跳变、两台手机并发、AAC-ELD、30 分钟听感等门禁继承 KNOWN-LIMITATIONS.md。本次未修改采集、解码或混音算法，不能宣称音质问题已经解决。
