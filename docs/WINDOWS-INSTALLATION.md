# Windows 安装与首次使用

支持 Windows x64。macOS 不支持。安装包无需用户预装 Node.js、Rust 或编译工具。

1. 运行 `MeshAudio_0.3.1_x64-setup.exe`，按安装向导完成。安装位置默认在当前用户目录，无需管理员安装主程序。
2. 缺少 Microsoft Edge WebView2 时，安装器会下载并安装运行环境，需要网络。
3. 首次打开，在引导中选择需要的组件，点击「安装所选组件」。已检测到的组件不会重装。
4. 使用 AirPlay 时需要 Bonjour；把声音作为其他应用的麦克风时需要 VB-CABLE。系统播放和基础路由不需要 VB-CABLE。
5. 第三方安装器可能要求 Windows 管理员确认、同意许可或点击 Install。驱动提示重启时，先保存其他工作再重启；应用不会强制重启电脑。
6. 在 iPhone 控制中心手动选择新建的 AirPlay 线路。二维码打开连接说明和网页麦克风页面，不会自动代替系统选择器。
7. 按住来源圆形端口拖到通道，松开连接；再将通道拖到系统播放或虚拟输出。绿色目标与预览线表示可连接，错误目标有文字提示。拖到空白或按 Esc 取消。
8. 鼠标只悬停在画布上时，滚轮滚动整个页面。点击画布后边框变蓝，滚轮才控制画布内部；点击外部或按 Esc 退出。选中连线后，点击曲线中间的删除按钮可移除该线路，其他线路不变。

## 按需组件

- Bonjour：从 Apple 官方下载，验证 Apple 签名，检测 Bonjour Service 与 x64 dnssd.dll。服务未运行时请修复安装或重启服务，再在设置刷新。
- VB-CABLE：从 VB-Audio 官方下载，固定 SHA-256，验证发布者签名；写入 CABLE Input，目标应用选择 CABLE Output 作为麦克风。
- UxPlay：应用随包提供的独立接收插件，只在画布添加/启动线路后启用，音频经过 MeshAudio 路由，关闭视频输出。
- UxPlay 无需另行下载或编译，安装主程序时自动部署。「设置 → 组件 → 自动配置 AirPlay」会检查插件，并自动下载、校验、安装缺少的 Bonjour。插件已安装与 AirPlay 已就绪分别显示；需要 UAC、取消、失败或重启时保留明确状态。自动配置不会自行启动接收线路。插件文件缺失时请重新运行完整安装包修复。

可在「设置 → 重新打开使用引导」重新选择组件。下载失败、签名变化、用户取消、安装失败均会明确显示；不要从不明镜像站获取驱动。下载缓存可由设置中的目录入口查看；组件缓存清理不代表卸载系统驱动。系统组件的卸载请使用 Windows 已安装应用或发布者卸载器。

## 防火墙

只在可信专用网络允许局域网访问。不要关闭整个防火墙。高级用户可检查 `tools/configure-airplay-firewall.ps1` 后以管理员运行，并将 NativePath 指向已安装应用的 UxPlay。脚本规则限定为 Private 与 LocalSubnet。公司网络、无线客户端隔离或访客网络可能阻断设备发现。

## 数据与卸载

配置保存在 `%APPDATA%/com.meshAudio.desktop/`，包含来源、通道、路由、组件状态和首次引导完成记录。升级保留配置。关闭主窗口会隐藏到托盘；从托盘选择退出才会停止服务。卸载主程序不自动卸载其他厂商的驱动/服务，不清除用户配置。

没有声音时先检查来源正在播放、两段路由、各级静音/增益和系统输出设备；虚拟麦克风还需检查目标应用是否选中 CABLE Output。详情中的延迟不包含完整 AirPlay 端到端等待时间。
