## 发布文件与复现

安装器位于 release/MeshAudio_0.3.0_x64-setup.exe。公开目录与两个源码归档、SHA256SUMS.txt 由 tools/export-public-source.js 生成。源码采用允许清单，未导出本机配置、开发工具、个人交接、日志、测试音频、编译缓存或嵌套 Git 元数据。构建和检查命令见 PUBLIC-BUILD.md、RELEASE.md。

机器可读本地证据保存在 docs/testing/ 与 .build-tools/；其中可能包含本机 IP/路径，因此不进入公开源码包。公开验收记录保留测试范围，不用删除失败历史来伪造全绿。
