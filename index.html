MeshAudio

LAN AUDIO ROUTING
把手机的声音，接到你想让它去的地方
下载 v0.3.1 GitHub 仓库

它能做什么

手机刷视频的声音、手机的麦克风，在 MeshAudio 里是两路独立的音频来源。 你在一张三列画布（音频来源 → 混音通道 → 外部输出）上拖几根线，就能决定： 哪一路进耳机、哪一路变成电脑上的麦克风给会议软件用、哪几路混在一起。 改线随时生效，不会影响其他链路。

  • 手机声音 → 耳机：媒体音频走混音通道进系统播放设备
  • 手机麦克风 → 电脑麦克风：接入微信 / Zoom / 会议软件的虚拟输入
  • 自由混音：来源可一对多、通道可多对一，带音量、静音与电平显示
  • 不会打断：单路断开其他链路照常播放，恢复后自动接回
  • 多种接入：Android App、iPhone AirPlay、电脑浏览器网页麦克风

快速开始

  • 从 Releases 下载 Windows 安装包与 Android APK，建议用 SHA256SUMS.txt 校验
  • 手机与电脑连到同一可信局域网，App 自动发现电脑即可连线
  • 接 iPhone：控制中心「屏幕镜像」选择电脑（需先在应用内安装 Bonjour 组件）
